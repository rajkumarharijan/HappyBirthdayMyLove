# Happy Birthday My Love 💗

A surprise birthday website. Single page, no build step: just `index.html`.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g. `for-my-love`).
2. Upload `index.html`, `.nojekyll` and `README.md` to the repository root
   (Add file → Upload files → Commit changes).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*,
   choose branch **main** and folder **/ (root)**, then click **Save**.
5. Wait 1–2 minutes. Your site will be live at:
   `https://<your-username>.github.io/<repo-name>/`
